# Amazon Sales Data Analytics Project

An end-to-end analysis of Amazon sales data using Python and Power BI.

## Project files

- `Amazon Sales data.csv` — source sales dataset.
- `Analyzing Amazon Sales data.ipynb` — Python analysis notebook.
- `Analyzing Amazon Sales data.html` — exported notebook for browser viewing.
- `Amazon Sales data.pbix` — interactive Power BI report.
- PDF files — project report and exported Python and Power BI analyses.

## Getting started

Open the notebook in Jupyter to follow the analysis. Open the `.pbix` file in Power BI Desktop to explore the report. The notebook uses the CSV dataset in this directory.
